# overdrive-pedal-analysis

A Python-based signal analysis comparing 10 drive pedal settings, all recorded from the same looped source. The analysis covers frequency response, spectral change over time, dynamics, harmonics, noise and similarity between pedals, and summarizes each pedal's characteristics along with a priority ranking of which pedals to keep.

The documentation in `docs/` is written in Japanese.

All gain and EQ knobs were set to 12 o'clock.

## Recording setup

A single guitar note (fundamental around 221 Hz) was recorded as a loop on a Ditto 2, and the same loop was played back through the following chain for every recording:

Ditto 2 → Strymon Compadre (off, buffer only) → drive pedal → DSM & Humboldt Simplifier MK-II (MS-Brit, cabinet: Stack / Blue) → UAFX Orion Tape Echo (in the send/return loop, echo off, preamp on)

After recording, the gain of each file was adjusted in Logic Pro so that the peaks were at roughly the same level. See [docs/pre-process.md](docs/pre-process.md) for details.

## Reproducing the analysis

Requires Python and [uv](https://docs.astral.sh/uv/). uv installs the dependencies at run time.

```sh
# 1. Preprocessing: read wav/ and write wav/aligned/
uv run --with numpy --with scipy --with soundfile python tools/align_trim.py

# 2. Analysis by measurement type: docs/figures/*.png, docs/metrics.csv, docs/distance_segments.csv
uv run --with numpy --with scipy --with soundfile --with matplotlib --with librosa python tools/analyze.py

# 3. Per-pedal figures and rankings: docs/figures/pedals/*.png, docs/pedal_ranks.csv
uv run --with numpy --with scipy --with soundfile --with matplotlib --with librosa python tools/pedal_profiles.py
```

Figures use the Hiragino Sans font (bundled with macOS) for Japanese labels.
