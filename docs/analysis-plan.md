# 解析仕様（analysis-plan）

Updated: 2026-11-16

前処理（[pre-process.md](pre-process.md)）を終えたファイルについて、解析の項目と方法を定める。実際に解析して問題があれば、この仕様を見直す。結果は [analysis.md](analysis.md) にまとめる。

## 共通ルール

- 入力：`wav/aligned/*.wav`（8.336 秒、48kHz / 24bit / 2ch）。L/R を平均したモノラルで解析する。ノイズの解析（E）だけは、元ファイル（`wav/*.wav`）の立ち上がり前の区間を使う
- 音量：録音後、ペダルごとに音の大きさが違ったため、Logic Pro で Gain プラグインを挿し、ピークが同程度になるように調整してある。そのため解析では正規化しない。ピークを揃えると、圧縮の強いペダルほど RMS が大きくなる。そこで、スペクトルを Raw と比べるとき（A2）は全体のパワーを揃えて形だけを比べる。比や相対値で求める指標（帯域別エネルギー比、減衰カーブ、サステイン、アタック、クレストファクタ、スペクトル重心、倍音、MFCC 距離）は、この調整の影響を受けない
- 周波数範囲：録音経路（DSM & Humboldt Simplifier MK-II のキャビネットシミュレーション）で 5〜6kHz より上がカットされているため、帯域や倍音の解析は 5kHz までを対象とする
- 図：測定の種類ごとに 1 枚とし、全ペダルを 1 つのグラフに重ねて比較する
- ペダルの色：全ての図で同じペダルには同じ色を使う。系統（メーカー・モデル）ごとに色を決め、同じ系統の設定違いは線種（実線・破線・点線）で区別する。Raw は黒の破線で基準として表示する
- 出力：`docs/analysis.md`（図と数値の表）、`docs/figures/*.png`
- スクリプト：`tools/analyze.py`

## 解析項目

### A. 周波数特性（音色）

| 項目 | 方法 |
|---|---|
| A1. 平均スペクトル | Welch 法で求め、1/6 オクターブで平滑化する |
| A2. Raw との差分 | 全体のパワー（20Hz 以上）を揃えたうえで、A1 の各ペダルから Raw を引く |
| A3. 帯域別レベル | 各帯域のエネルギー比 |

帯域の区切り：低域 <250Hz、中低域 250–500Hz、中域 500Hz–1kHz、中高域 1–2kHz、高域 2–5kHz

### B. 時間変化

| 項目 | 方法 |
|---|---|
| B1. スペクトログラム | STFT |
| B2. スペクトル重心の時間変化 | フレームごとの重心周波数（約 0.1 秒の移動平均）。RMS がノイズフロア +15dB を下回るフレームは除く |

### C. ダイナミクス

| 項目 | 方法 |
|---|---|
| C1. 減衰カーブ | RMS エンベロープ（dB と時間） |
| C2. サステイン | ピークから -10dB と -20dB に下がるまでの時間 |
| C3. アタック時間 | エンベロープが 10% から 90% に上がるまでの時間 |
| C4. クレストファクタ | 立ち上がりから 2 秒間のピーク値と RMS の比 |

### D. 歪みの性質（倍音解析）

音源が単音（基音 221.1Hz）なので、倍音ごとに分けて解析する。対象は立ち上がりから 2 秒間、1〜20 次（4.4kHz まで）。各倍音のパワーは、倍音の周波数 ±6% の範囲の合計とする。

| 項目 | 方法 |
|---|---|
| D1. 倍音ごとのレベル | 基音を 0dB としたときの各倍音のレベル |
| D2. Raw との差 | D1 の各ペダルから Raw を引く |
| D3. 倍音の指標 | 倍音比（2〜20 次の合計／基音、THD に相当）、偶数次／奇数次（2, 4, … 次の合計／3, 5, … 次の合計）、倍音／倍音以外の成分 |

倍音には、ギターと録音経路（Simplifier MK-II、Orion のプリアンプ）による倍音も含まれる。そのため、値そのものより Raw との差で比べる。

### E. ノイズ

| 項目 | 方法 |
|---|---|
| E1. ノイズフロア | 前処理で測定した値（50ms ごとの RMS の中央値）。ピークを揃えてあるため、ピークに対するノイズの大きさを表す |
| E2. ノイズのスペクトル | 元ファイルの立ち上がり前の区間について、8192 点のフレームごとのパワーの中央値を求める |
| E3. ヒス | E2 の 2–5kHz の帯域レベル。区間内の音程成分は 1kHz 付近までに出るため、それより上の帯域で評価する |
| E4. ハム | 50, 60, 100, 120, 150, 180Hz の各ピークが周囲（±4〜15Hz）の中央値を上回る量の最大値 |

### F. 総合的な類似度

| 項目 | 方法 |
|---|---|
| F1. 距離行列 | MFCC（1〜13 次。音量を表す 0 次は除く）の時系列について、フレームごとのユークリッド距離の平均。Raw がピーク比 -40dB 以上の区間を対象とする |
| F2. 系統分け | 階層クラスタリングの樹形図と MDS 配置図 |
| F3. 区間ごとの距離 | F1 と同じ距離を、立ち上がり（0〜0.3 秒）、持続部（0.3〜2 秒）、減衰部（2〜5 秒）に分けて求める。区間ごとに距離の大きさが違うため、全組み合わせの中央値と比べて読む |

## 変更履歴

### 2026-11-16（初回の解析後）

| 変更 | 理由 |
|---|---|
| D を倍音解析に置き換えた（旧：スペクトル平坦度、HPSS） | 音源がコードではなく単音だった。単音では平坦度がほぼ 0、調波成分は全ペダル 98〜99.5% となり、差が出ない。一方、倍音ごとの解析はできる |
| A3 の帯域を 5kHz までの 5 区分にした | 5kHz 以上のエネルギーは全ペダルでほぼ 0% |
| B2 でノイズフロア付近のフレームを除いた | 音がノイズに埋もれる 4 秒以降、ノイズの重心を測ってしまい、Raw などの重心が上がり続けていた |
| E にヒスとハムの指標を加えた | 立ち上がり前の区間には、弦の共鳴など演奏の音程成分が混ざる。そのため帯域を分けて評価する |

### 2026-11-16（録音条件の確認後）

| 変更 | 理由 |
|---|---|
| A2 で、全体のパワーを揃えてから Raw と比べるようにした。表示範囲は 6kHz まで | 録音後にピークを揃える調整をしていた。ピークを揃えると圧縮の強いペダルほど全体のレベルが上がり、差分のグラフ全体が上にずれていた。7kHz 以上はどのファイルも成分がほぼなく、差に意味がない |
| E1 のノイズフロアを、ピークに対するノイズの大きさとして扱うことにした | 同上 |

### 2026-11-16（聴感との比較後）

| 変更 | 理由 |
|---|---|
| F3（区間ごとの距離）を加えた | 聴感では Broadcast の音がほかとかなり違うのに、ファイル全体の MFCC 距離では Riverside low-mid に近い結果だった。全体の平均では時間の長い持続部と減衰部の影響が大きく、立ち上がりの違いが薄まるため、区間に分けて比べる |
